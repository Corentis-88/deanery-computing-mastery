## Programming language decision

For exams from 2027, AQA supports C#, Python 3 and VB.NET. The specification says candidates design, write, test and refine code in one of those languages. The Deanery publishes basic, advanced, robust and secure Python in its KS4 curriculum. Accordingly:

- Python receives deep practical treatment.
- Language-independent concepts and AQA pseudocode are taught explicitly.
- C# and VB.NET appear in a compact recognition/translation reference.
- Equal practical mastery of all three is not represented as a teacher requirement.

The live AQA subject page remains the authority for any future version change.
