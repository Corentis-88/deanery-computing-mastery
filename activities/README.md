# Practical activity pack

These files support the course tasks. Work on copies if you want to preserve a clean starter. Nothing here connects to a live school system, uses real pupil data, or authorises security testing.

- `python/`: Python 3 starters for Thonny. Each has a clear task and test prompts.
- `data/`: fictional CSV/text datasets for LibreOffice Calc or Python.
- `sql/`: a disposable SQLite database built from SQL source.
- `logic-lab.html`: an offline Boolean gate practice page.

The supplied files are deliberately small enough to inspect fully. Never paste credentials, pupil data or sensitive infrastructure information into them.
